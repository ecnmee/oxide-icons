Oxide Icons

Real <ox-icon> elements, real icon files from src/icons/, wired end to end: createIconSource to Registry to IsolationPolicy to SvgIconRenderer. See main.ts for the wiring, it is the only file in the whole project allowed to call import.meta.glob directly, see ADR-0014.

Usage

<ox-icon name="add" family="ui"></ox-icon>
<ox-icon name="add" size="32" color="#0a7d33" stroke-width="1.5"></ox-icon>

family is optional when the surrounding element declares data-icon-family, see the isolation section below.
